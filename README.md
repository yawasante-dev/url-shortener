# ⚡ URL Shortener

A full-stack URL shortening web app built with Python and Flask.

## 🚀 Features
- Shorten any long URL instantly
- Click a short link to be redirected to the original
- Tracks how many times each link has been clicked
- Clean, responsive dark-mode UI

## 🛠️ Tech Stack
- **Backend:** Python, Flask, Flask-SQLAlchemy
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript

## ⚙️ Run Locally

1. Clone the repo
```bash
   git clone https://github.com/yawasante-dev/url-shortener.git
   cd url-shortener
```

2. Create and activate a virtual environment
```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
```

3. Install dependencies
```bash
   pip install -r requirements.txt
```

4. Run the app
```bash
   python app.py
```

5. Open your browser and go to `http://127.0.0.1:5000`
